Servicio recurrente · Mantenimiento mensual

Un sitio web necesita revisión periódica, aunque no cambie.

Las métricas de Google se recalculan con datos reales de usuarios, el marcado estructurado puede quedar desactualizado y los errores de indexación pasan desapercibidos. Una revisión mensual documentada los detecta a tiempo.

Las métricas cambian aunque el código no cambie

Core Web Vitals se calcula con datos de uso real. Puede variar por una imagen nueva, un cambio de servidor o de CDN.

El marcado estructurado se desactualiza

Puede quedar desfasado cuando cambia el contenido del sitio o las especificaciones de schema.org.

Los errores de indexación pasan desapercibidos

Los errores de cobertura en Search Console no avisan, y hay páginas que dejan de indexarse.

El mantenimiento mensual es una revisión con registro escrito. Detecta estos problemas mientras todavía son pequeños.

Dos niveles de mantenimiento

Ambos se presupuestan a medida. El valor se informa en la videollamada o en la propuesta.

Mantenimiento técnico

Cada mes:

  • Revisión de Core Web Vitals (LCP, INP y CLS) en Search Console cuando hay datos suficientes; si el sitio tiene poco tráfico, se informa y se mide con PageSpeed Insights.
  • Revisión de cobertura e indexación.
  • Validación del marcado estructurado con Schema Markup Validator.
  • Medición con PageSpeed Insights en móvil y escritorio, con captura.
  • Copia de seguridad del código en GitHub o Google Drive.
  • Un cupo mensual de horas para cambios menores, definido en la propuesta.
  • Reporte escrito con capturas y lista de tareas.

Mantenimiento técnico y contenido

Todo lo anterior, más:

  • Un artículo mensual, de extensión acordada, con investigación de palabras clave. Se publica en su sitio con marcado Article y, si corresponde, FAQPage.
  • Consulta manual en ChatGPT, Perplexity y Google con las palabras clave del artículo, para registrar si el contenido aparece.
  • Registro acumulado de los artículos y de su posición en Search Console.

No se garantizan posiciones ni menciones en buscadores de IA.

No incluye: redes sociales, rediseño o sitio nuevo, ni monitoreo en tiempo real o soporte las 24 horas.

Qué se hace cada mes

Nivel técnico

  1. Revisión de Search Console.
  2. Validación de datos estructurados y medición de PageSpeed. Si el resultado baja del umbral acordado, se propone la corrección.
  3. Cambios menores y resolución de incidencias dentro del alcance.
  4. Copia de seguridad y reporte.

Nivel técnico y contenido

  1. Investigación de palabras clave.
  2. Borrador del artículo para su revisión.
  3. Publicación y consulta en buscadores de IA.
  4. Reporte acumulado.

Este nivel incluye también el protocolo técnico completo.

Alcance y responsabilidades

  • Lo que se detecta dentro del alcance se corrige en el ciclo, sin costo adicional.
  • Si usted modifica el sitio por su cuenta y algo se rompe, se documenta y se cotiza aparte.
  • El borrador del artículo requiere su aprobación. Los tiempos de revisión se acuerdan en la propuesta.
  • No se prometen posiciones ni resultados: dependen de factores que no controlamos.

Preguntas frecuentes

¿Necesito mantenimiento si mi sitio es estático y no usa WordPress?

Sí. Aunque el código no cambie, las métricas de Core Web Vitals se actualizan con datos reales de usuarios, el marcado estructurado puede quedar desactualizado y pueden aparecer errores de indexación. El mantenimiento cuida la visibilidad y el rendimiento, no solo el código.

¿Cuánto cuesta?

El presupuesto se hace a medida, después de una videollamada de 30 minutos y de una revisión de su sitio. El valor se informa en la videollamada o en la propuesta, y no se publica.

¿Qué pasa si un mes no hay cambios que hacer?

El protocolo se realiza igual: revisión, medición, copia de seguridad y reporte. Si no hay nada que corregir, el reporte lo documenta.

¿Quién escribe el artículo del segundo nivel?

Lo redacta Cirujana Digital a partir de la investigación de palabras clave. Usted lo revisa antes de publicarlo; los tiempos de revisión se acuerdan en la propuesta.

¿Puedo empezar por el nivel técnico y pasar al otro después?

Sí. El cambio de nivel se acuerda por escrito en la propuesta.

¿Cómo sé que el trabajo se hizo?

Cada mes recibe un reporte escrito con capturas de PageSpeed y de Search Console, la lista de tareas realizadas con fecha y el enlace a la copia de seguridad.

¿Incluye redes sociales?

No. El servicio se limita al sitio web: rendimiento técnico, indexación, datos estructurados y, en el segundo nivel, contenido del sitio.
