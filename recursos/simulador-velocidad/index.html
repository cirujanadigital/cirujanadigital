Qué mide y qué no. Es un cálculo lineal simple: visitas × demora × supuesto. No considera el dispositivo, el origen del tráfico ni el tipo de página. La relación real entre velocidad y conversión varía de un sitio a otro; para conocer la suya hace falta medirla con datos propios.

Qué revisar primero

Causas frecuentes de una carga lenta. Un informe de PageSpeed Insights indica cuáles aplican a su web.

  • Imágenes sin optimizar o demasiado pesadas.
  • CSS y JavaScript que bloquean la carga inicial.
  • Caché del servidor sin configurar.
  • Ausencia de una red de distribución de contenido (CDN).
  • Hosting lento o exceso de complementos.
